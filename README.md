# 💧 JalRakshak – Water Quality Prediction

**JalRakshak** is a Flask-based Machine Learning web application designed to analyze water quality parameters and predict whether a given water sample is **safe or unsafe for consumption**.

The project provides a simple and user-friendly web interface where users can enter water-quality parameters and receive an instant prediction generated by a trained Machine Learning model.

---

## 🌊 Project Overview

Access to safe and clean water is essential for human health and environmental sustainability. JalRakshak aims to provide a simple AI-powered solution for preliminary water quality assessment.

The application combines:

* 🧪 Water quality parameters
* 🤖 Machine Learning
* 🌐 Flask web framework
* 🎨 HTML & CSS interface
* 📊 Data preprocessing and model prediction

Users enter the required water parameters through the web interface, and the trained Machine Learning model analyzes the input and generates a water quality prediction.

---

## 🚀 Features

* 💧 **Water Quality Prediction**

## ⚙️ Installation & Setup

Follow the steps below to run JalRakshak on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/khanzainabshuaib/Jalrakshak-Water-Quality-Prediction.git
```

Move into the project directory:

```bash
cd Jalrakshak-Water-Quality-Prediction
```

---

### 2. Create a Virtual Environment

#### Windows

```bash
python -m venv venv
```

Activate the environment:

```bash
venv\Scripts\activate
```

#### macOS / Linux

```bash
python3 -m venv venv
```

Activate the environment:

```bash
source venv/bin/activate
```

---

### 3. Install Dependencies

Install the required Python packages:

```bash
pip install -r requirements.txt
```

---

### 4. Run the Flask Application

Start the application:

```bash
python app.py
```

You should see a message similar to:

```text
Running on http://127.0.0.1:5000/
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```

## 🧪 Machine Learning Workflow

JalRakshak follows a basic Machine Learning pipeline:

### 1. Data Collection

Water quality data is collected from the project dataset.

### 2. Data Preprocessing

The dataset is processed to handle:

* Missing values
* Invalid values
* Feature transformation
* Data scaling
* Data preparation

### 3. Exploratory Data Analysis

The dataset is analyzed using statistical methods and visualizations to understand relationships between different water quality parameters.

### 4. Model Training

Machine Learning algorithms are trained using the processed dataset.

### 5. Model Evaluation

The trained model is evaluated using appropriate performance metrics.

### 6. Model Deployment

The trained model is integrated into the Flask application.

### 7. Prediction

The user enters water quality parameters through the website, and the Flask application sends the data to the trained model to generate a prediction.
